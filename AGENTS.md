# Instructions pour les agents

Tu travailles en autonomie sur le simulateur de chaussettes jacquard César Bazaar.

1. Lis les règles dans `.cursor/rules/` (surtout `10-workflow.mdc`).
2. Lis `docs/CAHIER_DES_CHARGES.md`, `docs/ARCHITECTURE.md`, `src/core/types.ts`.
3. Traite `tasks/TASKS.md` dans l'ordre, une tâche à la fois, avec `npm run verify` comme juge.
4. Journalise dans `docs/PROGRESS.md`, décide seul et note tes décisions dans `docs/DECISIONS.md`.
5. Ne pose pas de question à César : il est indisponible. Enchaîne les tâches jusqu'au bout.
